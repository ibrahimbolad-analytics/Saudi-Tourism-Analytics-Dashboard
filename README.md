## 📊 Comprehensive Performance Analysis & Investment Opportunities Tracking (2019-2024)

A strategic business intelligence solution built to monitor Saudi Arabia's tourism transformation, tracking Vision 2030 progress and identifying high-impact investment opportunities across 13 regions.

---

## 🎯 Business Problem

Saudi Arabia's Vision 2030 aims to transform the tourism sector into a key economic pillar, targeting **150M annual visitors by 2030**. The challenge: How do we monitor progress across multiple dimensions (visitors, spending, infrastructure, regional distribution) and identify strategic investment opportunities in real-time?

**Key Questions Answered:**
- Are we on track to meet Vision 2030 targets?
- Where are the highest-ROI investment opportunities?
- How has COVID-19 recovery progressed?
- Which cities are emerging as growth leaders?
- What's the optimal timing for infrastructure expansion?

---

## 💡 Solution Approach

Built a **14-page interactive Power BI dashboard** that transforms 54+ raw Excel files from Saudi Open Data Portal into actionable strategic insights for policymakers, investors, and tourism operators.

### **Core Analytical Frameworks:**

1. **Vision 2030 Progress Tracker** 🎯
   - Real-time gap analysis vs. national targets
   - CAGR monitoring across all KPIs
   - Predictive trajectory modeling to 2030

2. **Investment Priority Scoring** 💰
   - Multi-factor algorithm combining:
     - Demand pressure index (visitor/room ratio)
     - Infrastructure gap analysis (200K national shortage)
     - Growth trajectory (regional CAGR 2019-2024)
     - Regional market share & economic impact
   - City-level investment rankings with ROI indicators

3. **Economic Impact Modeling** 📈
   - Direct, indirect, and induced spending calculations
   - Employment multiplier analysis (1.8x factor)
   - GDP contribution tracking (7.1% in 2024)
   - Net foreign exchange quantification

4. **Supply-Demand Balance Engine** ⚖️
   - 200K national room gap quantification (official targets)
   - Regional distribution optimization (37% Makkah, 18% Riyadh)
   - Occupancy-based capacity planning
   - 2030 infrastructure projections

### **Advanced DAX Calculations**

#### **Vision 2030 CAGR Monitoring**
```dax
CAGR_2019_to_Current = 
VAR Visitors_2019 = 
    CALCULATE([Total_Visitors], Dim_Date[Year] = 2019)
VAR Visitors_Latest = 
    CALCULATE([Total_Visitors], Dim_Date[Year] = MAX(Dim_Date[Year]))
VAR Years = MAX(Dim_Date[Year]) - 2019
RETURN
    IF(Years > 0 && Visitors_2019 > 0,
        POWER(DIVIDE(Visitors_Latest, Visitors_2019), 1/Years) - 1,
        BLANK()
    )
```

#### **Investment Priority Scoring Algorithm**
```dax
Investment_Priority_Score = 
VAR GapSize = [Regional_Official_Gap]
VAR MaxGap = MAXX(ALL(Dim_Region), [Regional_Official_Gap])
VAR GapScore = DIVIDE(GapSize, MaxGap, 0) * 40

VAR Growth = [CAGR_by_Region]
VAR GrowthScore = MIN(Growth * 100, 30)

VAR Pressure = [Demand_Pressure_Index]
VAR PressureScore = MIN(Pressure * 10, 30)

RETURN
    GapScore + GrowthScore + PressureScore
```

#### **Economic Impact Modeling**
```dax
Total_Economic_Impact = 
VAR DirectSpending = [Total_Spending_2024]
VAR Multiplier = 1.8  // Saudi tourism multiplier
RETURN DirectSpending * Multiplier

Jobs_Supported = 
VAR TotalImpact = [Total_Economic_Impact]
VAR JobsPerMillionSAR = 1  // Conservative estimate
RETURN ROUND(TotalImpact / 1000000 * JobsPerMillionSAR, 0)
```
